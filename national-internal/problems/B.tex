\begin{problem}{B}{Breaking the Glass}{X seconds}

\noindent
There is a table with $n$ rows and $m$ columns.
Each cell of the table contains a diagonal piece of glass in the shape of \verb|\| or \verb|/|, which splits that cell into two triangular halves.

\noindent
These diagonal pieces divide the interior of the table into one or more \textbf{regions}.
A region is a maximal connected open area: informally, any two points in the same region can be joined by a path that does not cross any glass.
Note that the borders of the table are \textbf{not} glass, so regions may extend to the edge of the table.
The space outside the table is not counted as a region.

\noindent
You want to merge all regions into a single connected region.
In one operation, you can break the glass in one cell, removing its diagonal piece entirely.
Determine the minimum number of operations required.

\InputFile

\noindent
First line of input contains two integers $n$ and $m$ ($1 \le n \times m \le 10^6$).\\
The next $n$ lines each contain a string of length $m$ consisting of characters \verb|\| and \verb|/|, representing the table.

\OutputFile

\noindent
Output the minimum number of operations required to merge all regions into one big region.

\Examples

\begin{example}
\exmp{1}{
5 6
/\textbackslash//\textbackslash/
\textbackslash/\textbackslash/\textbackslash/
/\textbackslash//\textbackslash/
\textbackslash/\textbackslash/\textbackslash/
\textbackslash/\textbackslash/\textbackslash/
}{
  13
}

\exmp{2}{
2 2
\textbackslash/
/\textbackslash
}{
  3
}
\end{example}

\end{problem}
