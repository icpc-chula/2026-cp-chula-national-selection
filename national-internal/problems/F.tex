\begin{problem}{F}{Fixing Fridge}{X seconds}

\noindent
Doraemon has a special 2-floor refrigerator with $n$ compartments on each floor used to store his favorite soft drinks. The current storage modes of the compartments are represented by a $2 \times n$ binary table $A$, where \texttt{0} means standard cooling and \texttt{1} means deep freeze. He wants to adjust the refrigerator to a perfect target state, represented by another $2 \times n$ binary table $B$.

However, Nobita keeps playing with the settings! There are $T$ events that can occur, given as queries:
\begin{itemize}
  \item \texttt{1 p q x y}: Nobita uses a gadget to invert the storage modes in a rectangular block of compartments from floor $p$ to $q$ and columns $x$ to $y$ (inclusive) in the current refrigerator state $A$. Here, $1 \le p \le q \le 2$, and $1 \le x \le y \le n$.
  \item \texttt{2}: Doraemon checks the refrigerator and wants to know: what is the minimum number of operations required to transform the current state $A$ into his perfect target state $B$? In a single operation, Doraemon can use his ``Rectangle Flipper'' gadget to choose any subrectangle of compartments in $A$ and invert all their modes (change \texttt{0} to \texttt{1} and \texttt{1} to \texttt{0}).
\end{itemize}

\noindent
Note that a subrectangle is defined by choosing two floors (rows) and two compartments (columns), and it includes all compartments in the rectangle formed by them.

\InputFile

\noindent
The first line of input contains an integer $n$ ($1 \le n \le 10^5$), representing the number of compartments on each floor.\\
The second line contains the first floor's current state $A_0$ ($|A_0| = n$).\\
The third line contains the second floor's current state $A_1$ ($|A_1| = n$).\\
The fourth line contains the first floor's target state $B_0$ ($|B_0| = n$).\\
The fifth line contains the second floor's target state $B_1$ ($|B_1| = n$).\\
The sixth line contains an integer $T$ ($1 \le T \le 10^5$), representing the number of events.\\
The next $T$ lines contain the queries in the format described above (\texttt{1 p q x y} or \texttt{2}).

\OutputFile

\noindent
For each query of type \texttt{2}, output a single integer: the minimum number of operations Doraemon needs to transform the refrigerator's current state $A$ into the target state $B$.
